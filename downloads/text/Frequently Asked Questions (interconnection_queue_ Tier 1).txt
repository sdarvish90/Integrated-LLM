Frequently Asked Questions
Does SPP accept both 2-winding and 3-winding transformers in submittals?
Yes; both 2-winding and 3-winding transformers will be allowed as part of proposed projects.
Can sequence data be provided using PSSE BAT command format in an idev or does it have to be provided in a separate .seq file in addition to the idev file?
SPP will gladly accept sequence data in either format.
Are connection codes required for transformers in PSSE?
Yes; please provide the codes that refer to the proper winding type as defined in the PSSE manual.
Are PSSE slider files required for each submittal?
No, slider files are not required.
Have a question that isn’t answered here? Please submit a ticket through
SPP’s Request Management System (RMS).
